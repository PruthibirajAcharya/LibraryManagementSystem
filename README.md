Library Management System
- A Salesforce-based Library Management System to manage library members, books, transactions, and membership plans efficiently.

Features
- Manage Library Members and Membership Plans
- Issue and Return Books
- Track Due Dates for Transactions
- Built with Salesforce Custom Objects and Relationships

Usage

1. Log in to your Salesforce org.
2. Use the custom tabs for managing:
	-Books
	-Library Members
	-Transactions
	-Membership Plans
3. Create and track book transactions, including issuing and returning books.
